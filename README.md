# GRC206: Security Awareness Program

## Project Overview
This project focuses on developing a Security Awareness Program for Northbridge Logistics.

## Objectives
The program aims to:
- Educate employees about cybersecurity threats.
- Promote safe online practices.
- Reduce security risks caused by human errors.
- Build a strong security awareness culture.

## Contents
This repository contains the GRC206 assignment document, including the security awareness plan, objectives, and 12-month awareness calendar.
